KRITERIA 1: Seluruh Kriteria Submission Pertama Terpenuhi (Advance)

- Standar Aksesibilitas WCAG: Skip to content link, alt text lengkap, label form eksplisit, kontras warna tinggi, navigasi keyboard penuh (Tab/Enter/Space).
- Responsif di seluruh breakpoint perangkat (375px mobile, 768px tablet, 1024px+ desktop).

KRITERIA 4: IndexedDB (Advance)
- Menerapkan IndexedDB (`dicostory-db` versi 2) menggunakan library modern `idb`:
  1. Konten Dinamis Offline (Advance):
     * Data cerita dari API otomatis dicache ke IndexedDB object store `cached-stories`.
     * Saat diakses dalam keadaan offline, daftar cerita dan detail cerita tetap muncul dan dapat dilihat dengan baik oleh pengguna.
  2. Cerita Tersimpan (Bookmark Offline):
     * Object store `favorite-stories` untuk menyimpan cerita favorit.
     * Halaman khusus `#/saved` lengkap dengan pencarian real-time, sorting, dan hapus cerita.
  3. Offline Background Synchronization (Outbox Queue) (Advance):
     * Object store `outbox-stories`: Saat membuat cerita saat offline (!navigator.onLine), cerita disimpan di antrean outbox.
     * Ketika koneksi internet pulih (event `online` atau Service Worker `sync`), modul `SyncHelper` otomatis mengunggah cerita ke API Dicoding dan memberikan notifikasi sukses!
